# Bagi Kopi Outlet Map

Interactive map of Bagi Kopi outlets in Java (Jabodetabek, Bandung Raya, Surabaya).
Hover or tap a pin to see the outlet name; use the area buttons to zoom in.

Live page: `https://<your-username>.github.io/<repo-name>/`

Built with [D3.js](https://d3js.org). Map outline: Natural Earth.
